# Calculadora de Propinas Pro 💰

¡Bienvenido a la Calculadora de Propinas Pro! Este es un programa interactivo desarrollado en Python diseñado para simplificar la división de cuentas en restaurantes o eventos, calculando de manera automática el monto exacto por persona.

## 🚀 Características
* **Modularidad con Funciones:** Toda la matemática pesada está aislada en una función dedicada (`calcular_division_cuenta`), siguiendo los principios de código limpio.
* **Cálculo de Impuestos Automatizado:** Incluye una opción configurada para añadir el 18% del impuesto local (ITBIS de República Dominicana) si el usuario lo desea.
* **Manejo de Errores (A prueba de balas):** Implementación de bloques `try-except` para evitar que el programa se rompa si el usuario introduce letras en lugar de números.
* **Bucle Continuo controlled:** Usa un ciclo interactivo que permite realizar múltiples cálculos en la misma sesión sin reiniciar la consola.

## 🛠️ Tecnologías Usadas
* Python 3.14
